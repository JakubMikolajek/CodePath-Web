# PDF export fonts

TTF files loaded lazily by the docs PDF export (`lib/docs-pdf`).

- `Roboto-*.ttf` (Regular, Medium used as bold, Italic, MediumItalic): Roboto, Apache License 2.0, copied from the fonts shipped inside the `pdfmake` package.
- `DejaVuSansMono*.ttf`: DejaVu Sans Mono 2.37 (source: npm `dejavu-fonts-ttf`).
